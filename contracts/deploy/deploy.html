Burn program deployer

Deploys the ownerless CLG price oracle and one burn redeemer per collection from your own wallet, then helps you fund them. Nothing here holds keys; every step is a wallet transaction you approve. Parameters come from contracts/deploy/addresses.json.

Order of operations

  1. Connect the project wallet (0xAF87…175D), so the contracts record it as their deployer.
  2. Send the project wallet's own Legends Awaken NFTs to 0x…dEaD first (e.g. with crovia.app/tools/burn), so the team can never redeem from the reserve.
  3. Deploy the oracle. Set up the keeper (the POKE_PRIVATE_KEY secret of the burn monitor) right away: the oracle needs a checkpoint about every hour.
  4. Wait 24 hours. Deploy the redeemers any time; they can't pay until the oracle is warm.
  5. Only fund a redeemer once its payout below shows about $35 (or $15 for Elderborn).
  6. Put the addresses into assets/data/burn.json, verify both contracts on the explorer, and publish the site.
